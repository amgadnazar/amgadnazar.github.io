## Getting Started

Clone the repository

```bash
git clone https://github.com/amgadnazar/amgadnazar.github.io.git
```

Move into the project directory

```bash
cd amgadnazar.github.io
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Deploy to GitHub Pages

```bash
npm run deploy
```
