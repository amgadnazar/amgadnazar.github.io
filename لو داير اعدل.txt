الخطوات التي ستكررها كل مرة هي:

cd C:\Users\HP\Desktop\amjad-portfolio-v2

git checkout master

اعمل أي تعديل في المشروع.

ثم:

git add .
git commit -m "Describe your changes"

ثم انشر الموقع:

npm run deploy

بعد أن ينتهي:

git checkout gh-pages
git pull origin gh-pages

ثم ارجع للكود:

git checkout master
تأكد دائمًا أنك تعدل على الفرع الصحيح

قبل أن تبدأ أي تعديل نفذ:

git branch

إذا ظهرت النجمة هكذا:

* master
  gh-pages

فأنت في المكان الصحيح.

إذا ظهرت:

* gh-pages

ارجع مباشرة:

git checkout master

ولا تعدل أي ملف وأنت على gh-pages لأنه فرع النشر فقط.

نصيحة

بعد الذي حصل اليوم، الأفضل تضيف dist وnode_modules إلى .gitignore (إذا لم يكونا موجودين)، حتى لا يدخلوا في فرع master ويكبر الريبو بدون داعٍ.

بهذا أصبح عندك نظام واضح:

master → تكتب الكود.
npm run deploy → ينشر إلى gh-pages.
gh-pages → لا تلمسه إلا إذا اضطررت.
